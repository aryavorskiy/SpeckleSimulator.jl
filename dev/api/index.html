Setting up the atmosphere model

AtmosphericTurbulenceSimulator.HardingInterpolator — Type
HardingInterpolator([T, ]size_to[; batch, deviceadapter, nsteps, size_from, size_heuristics])

Upsample low-resolution phase screens to size_to with several passes of Harding interpolation. When the interpolator is constructed, the batch is split into one chunk per worker (see get_num_threads()), and the chunks are interpolated in parallel.

Holds scratch buffers only — the caller owns both the input and the output; see harding_interpolate!. The size of the low-resolution input is the first entry of the stage_sizes field.

Arguments

  • T: element type of the scratch buffers (default Float64).
  • size_to: the size of the output phase screens.

Keyword Arguments

  • batch: number of screens interpolated per call (default 1).
  • deviceadapter: storage adapter for the scratch buffers (default identity, i. e. no transform).
  • nsteps: number of passes of Harding interpolation. If set to :auto, the number of passes will be chosen automatically (default).
  • size_from: alternatively, specify the low-res grid size directly. This must be greater than (11, 11) in each dimension.
  • size_heuristics: when nsteps=:auto, the maximum allowed number of pixels in the low-res grid. Tweak this based on the capability of your hardware to compute eigen of a N×N matrix, where N is the number of pixels in the low-res grid.

AtmosphericTurbulenceSimulator.KarhunenLoeveSampler — Type
KarhunenLoeveSampler(shape, covmat[; batch, deviceadapter])
KarhunenLoeveSampler(shape, (E, U)[; batch, deviceadapter])

Draw phase screens by a Karhunen-Loeve expansion of a phase covariance matrix.

Holds precomputed constants and scratch space only — the caller owns the output array. Use samplephases! to draw a batch into an array of your own.

Arguments

  • covmat: an N×N phase covariance matrix with N == prod(shape), e.g. from kolmogorov_covmat. Any symmetric covariance works, not only Kolmogorov.
  • (E, U): a precomputed eigendecomposition of covmat.
  • shape: the (nx, ny) shape of one phase screen.

Keyword Arguments

  • batch: number of screens drawn per samplephases! call (default 1).
  • deviceadapter: storage adapter for the noise transform and the scratch buffer (default identity). Given covmat, the eigendecomposition runs on the device if the adapter supports it, otherwise on the host.

AtmosphericTurbulenceSimulator.PhaseBuffers — Type
PhaseBuffers(atm_spec::SingleLayer, plate_size[, d][; grid_step, batch, deviceadapter])

Everything needed to draw batches of phase screens. Owns no output array — allocate one with allocate_phases and pass it to samplephases!.

Groups a sampler (KarhunenLoeveSampler), a scratch buffer for low-resolution phase screens, a HardingInterpolator for upsampling, and the additional scale factor encoding the $r_0$. Saved phase screens are replayed by a SavedPhaseReader instead.

Arguments

  • atm_spec: an AtmosphereSpec describing the turbulence.
  • plate_size: (nx, ny) size of the generated screens.
  • d: aperture diameter in the same units as $r_0$; plate_size must be square when d is used.

Keyword Arguments

  • grid_step: physical size of one pixel; overrides the value derived from d.
  • batch: screens per samplephases! call (default 1).
  • deviceadapter: storage adapter for the buffers (default identity, i. e. no transform).

AtmosphericTurbulenceSimulator.SavedPhases — Type
SavedPhases(dataset[, d]; wind_velocity, base_wavelength, grid_step)

An AtmosphereSpec that reuses phase screens saved in a dataset.

The dataset must match the phase-screen layout written by simulate_phases and simulate_images. Frames are read in order; if more frames are requested than available, an error is thrown, there is no guarantee what is in the tail of the last batch.

Arguments

  • dataset: a 3D array-like containing phase screens with dimensions (nx, ny, nframes). This can be an in-memory array or an HDF5 dataset (e.g. HDF5.Dataset).
  • d: aperture diameter of the saved phase screens. Optional; when omitted tries to infro from the imaging setup. Overriden by grid_step.

Keyword Arguments

  • base_wavelength: reference wavelength used to scale phase screens when a multi-wavelength FilterSpec is used. A Unitful length; a plain number is assumed to be nanometers (default 550 nm).
  • wind_velocity: two-component (vx, vy) wind velocity used for long-exposure offsets in imaging simulations (default (0, 0)).
  • grid_step: physical size of one aperture pixel. Overrides the value derived from d when provided.

AtmosphericTurbulenceSimulator.SingleLayer — Type
SingleLayer([T, ]r0[; base_wavelength, wind_velocity, harding])

An AtmosphereSpec that produces independent (uncorrelated) phase frames for each timestep.

Arguments

  • T: the number type for phase screens (default Float64).
  • r0: Fried parameter ($r_0$) in length units (e.g. 0.2m). A plain number is interpreted in whatever units d/grid_step uses.

Keyword Arguments

  • base_wavelength: reference wavelength used to scale phase screens when a multi-wavelength FilterSpec is used in length units (default 550 nm). A plain number is assumed to be nanometers.
  • wind_velocity: two-component (vx, vy) wind velocity used for long-exposure offsets in imaging simulations in velocity units (default (0, 0)). A plain number is assumed to be in whatever units d/grid_step and exposure use.
  • harding: keyword arguments passed to HardingInterpolator for optional multi-pass interpolation of low-resolution phase screens. Defaults to nsteps=:auto and size_heuristics=1024.

AtmosphericTurbulenceSimulator.harding_interpolate! — Function
harding_interpolate!(out, hi::HardingInterpolator, low[, r₀_px=1, α, β])

Run the full Harding ladder, interpolating low-resolution phase screens into higher ones.

Arguments

  • out: a (nx_high, ny_high, batch) array to hold the upscaled phasescreens.
  • hi: a HardingInterpolator holding scratch buffers and ladder parameters.
  • low: a (nx_low, ny_low, batch) array of low-resolution phase screens.
  • r₀_px: Fried parameter of the low-resolution screens in pixels (default 1). The high-resolution output will have the same r₀_px in pixels.
  • α and β: optional scaling factors for the output. If provided, the result is computed as $out = α ⋅ harding_interpolate(low) + β ⋅ out$.

AtmosphericTurbulenceSimulator.harding_upsample! — Function
harding_upsample!(to, from[, r₀_px=1; rescale=true])

One pass of Harding interpolation: the (n, m, batch) phase screen from is upsampled onto the (2n-1, 2m-1, batch) grid to.

r₀_px is the Fried parameter of from in pixels (default 1). With rescale=true (the default) the output is scaled by $2^{5/6}$ so that to has the same r₀_px in pixels as from — which is what makes every pass of a multi-pass ladder identical. With rescale=false the physical screen is preserved instead and r₀_px doubles, so a ladder must then decay its injected noise by $2^{5/6}$ per pass. The two conventions differ by exactly $2^{5N/6}$ after N passes.

The outermost 5 rows and columns of to are left uninterpolated — their stencils would run off the grid — which is why harding_interpolate! crops [6:end-5, 6:end-5, :] between passes.

Reference: C. M. Harding, R. A. Johnston and R. G. Lane, "Fast simulation of a Kolmogorov phase screen", Applied Optics 38(11), 1999.

AtmosphericTurbulenceSimulator.kolmogorov_covmat — Function
kolmogorov_covmat(W[, r₀_px])
kolmogorov_covmat([T, ]size[, r₀_px])

Compute the phase covariance matrix of a turbulent layer in the atmosphere, following the Kolmogorov model. The piston term is excluded in this model.

Arguments

  • T: number type for the covariance matrix (default matches r₀ if provided, otherwise eltype(W) or Float64).
  • W: the aperture function as a 2D array of weights. Normalized to sum(W) == 1 internally.
  • size: a tuple (nx, ny) specifying the size of the aperture function.
  • r₀_px: Fried parameter ($r_0$) in pixel units (default 1.0).

scale_phases!(phases, r₀[; grid_step])

Rescale phases in place to Fried parameter r₀, assuming they were generated with $r_0 = 1$ pixel.

AtmosphericTurbulenceSimulator.Exposure — Type
Exposure(exptime[, nsteps][; round_offsets])

A struct that encapsulates the exposure time and related parameters for long-exposure simulations. The exposure is simulated by averaging nsteps short exposures with appropriate offsets of the wavefront.

Arguments

  • exptime: total exposure time. Shares the same time units as the wind velocity in the atmosphere specification.
  • nsteps: number of steps to simulate for long exposures (default 5).
  • round_offsets: whether to round the exposure offsets to integers (default false). When true, the phase screens are sampled at integer pixel offsets, which can reduce interpolation artifacts.

AtmosphericTurbulenceSimulator.FilterChannel — Type
FilterChannel(interpolator, phs_factor, weight)
FilterChannel(aperture, lambda_rel, inten[, imgsize])

One sampled wavelength of the filter bandpass, bundling the three quantities derived from it: the plate-scale interpolator (a BilinearInterpolator built by BilinearScale), the phase scaling phs_factor ($λ_{base} / λ_w$) and the intensity weight. They are carried together because all three come from the same wavelength – keeping them apart meant recomputing the weight in the innermost loop.

AtmosphericTurbulenceSimulator.ImagingPlan — Type
ImagingPlan(atm_spec::AtmosphereSpec, img_spec::ImagingSpec)

Everything the optical pipeline needs that does not change during a run: the ImagingSpec, the atmosphere's base_wavelength, the per-exposure-step wind offsets, one FilterChannel per sampled wavelength, and psf_norm.

Holds no scratch and no output, so it is shared read-only by every worker – the per-wavelength interpolation tables exist once per run rather than once per thread. Built on the host; adapt it to a device before passing it to compute_psf! together with an OpticalBuffers. length(offsets) is folded into psf_norm, which compute_psf! divides by.

AtmosphericTurbulenceSimulator.ImagingSpec — Type
ImagingSpec

Container for the imaging system configuration. Fields: the telescope aperture, the grid_step (physical size of one aperture pixel, in the same units as $r_0$), the ReadoutSpec readout_spec describing the photon budget and readout, the spectral filter_spec, the exposure, and the output img_size. If img_size does not match the aperture’s Nyquist grid, the aperture is zero-padded accordingly.

Build it with the ImagingSpec(aperture, d, ...) constructor.

AtmosphericTurbulenceSimulator.ImagingSpec — Method
ImagingSpec([T, ]aperture[, d][, readout_spec][; grid_step, filter, exposure, nyquist_oversample, img_size])

Create an imaging system specification.

Arguments

  • T: desired number type, inferred from aperture if not provided.
  • aperture: 2D aperture (pupil) array describing the telescope pupil.
  • d: aperture diameter in the same units as $r_0$ (e.g. 2m). Used to compute grid_step = d / size(aperture, 1), which requires a square aperture. May be nothing if grid_step is given.
  • readout_spec: ReadoutSpec instance describing the photon budget and readout. Defaults to ReadoutSpec(Inf) (continuous flux, no noise).

Keyword Arguments

  • filter: FilterSpec describing sampled wavelengths and their relative intensities. Defaults to a monochromatic filter at 550 nm.
  • exposure: a number or an Exposure instance describing the exposure time and number of steps for long exposures. Defaults to zero exposure time (i.e. short exposure).
  • nyquist_oversample: multiplicative factor applied to the default Nyquist image size (2 * size(aperture)). Defaults to 1. Ignored if img_size is provided.
  • img_size: explicit output image size (nx, ny). If not provided, computed from aperture size and nyquist_oversample.
  • grid_step: physical size of one aperture pixel in the same units as $r_0$. Overrides the value derived from d.

AtmosphericTurbulenceSimulator.OpticalBuffers — Type
OpticalBuffers(plan::ImagingPlan[; batch, nthreads])
OpticalBuffers(spec::ImagingSpec[; batch, nthreads])
OpticalBuffers(img_array[, size][; batch, nthreads])

Scratch for the optical pipeline: two complex (img_size..., batch) buffers and the FFT plans over them. Nothing else – the per-wavelength constants live in ImagingPlan and the PSF accumulator and readout image are supplied by the caller, see compute_psf!.

The batch is split into at most nthreads contiguous chunks, each with its own FFT plan. Functions that take an OpticalBuffers process the chunks in parallel; with a single chunk they run directly.

Arguments

  • plan, spec: the buffers have size spec.img_size and are allocated like spec.aperture.
  • img_array: an array whose storage type and element type the buffers follow; size is the (nx, ny) size of the buffers (defaults to the first two dimensions of img_array).
  • pupil_buffer: a preallocated complex (nx, ny, batch) array to use as the pupil buffer.

Keyword Arguments

  • batch: number of frames processed per call (default 1). Not accepted by the pupil_buffer method, where the batch is the third dimension of the array.
  • nthreads: maximum number of worker threads (default get_num_threads()).

AtmosphericTurbulenceSimulator.ReadoutSpec — Type
ReadoutSpec(nphotons[, background, readout, bias, gain])

Specifies the photon budget and readout process for imaging simulations.

Arguments

  • nphotons: total expected number of photons in the image. Set to Inf for continuous flux (no noise is applied and background, readout, bias and gain are ignored).
  • background: expected number of background photons per pixel. Can be omitted if nphotons is Inf; required otherwise.
  • readout: standard deviation of the Gaussian readout noise, in photoelectrons (before gain). Defaults to 0 (no readout noise).
  • bias: constant offset added to every pixel after applying gain. Defaults to 0.
  • gain: multiplicative factor converting photoelectrons to output counts. Must be nonzero. Defaults to 1.

Each pixel is computed as gain * (Poisson(λ) + readout * randn()) + bias, where λ = nphotons * intensity + background, and then rounded to the output type.

AtmosphericTurbulenceSimulator.compute_psf! — Function
compute_psf!(psf, bufs::OpticalBuffers, plan::ImagingPlan, phases[, α, β])

Accumulate the point-spread function over every exposure offset and wavelength: psf = α * PSF(phases) + β * psf. Each contribution is already divided by plan.psf_norm, so the result can be passed to apply_truesky! and readout! as is. phases is an (nx, ny, batch) array with the batch length of bufs; the batch is processed in parallel chunks, see OpticalBuffers.

AtmosphericTurbulenceSimulator.phases_to_pupil! — Function
phases_to_pupil!(pupil, phases, aperture[, offset, phs_factor])
phases_to_pupil!(bufs::OpticalBuffers, phases, aperture[, offset, phs_factor])

Write the complex pupil field aperture * cis(phase * phs_factor) into pupil, zero-padded to the image grid and sampled at the wind offset.

offset is the (ox, oy) shift in pixels (default (0, 0)); phs_factor multiplies the phases (default true, i.e. no scaling). The OpticalBuffers method writes into bufs.pupil_buffer, processing chunks of the batch in parallel.

AtmosphericTurbulenceSimulator.pupil_to_psf! — Function

Propagate the pupil field currently in bufs to the focal plane and write its intensity into psf, rescaled to ch's plate scale: psf = α * ch.weight * intensity + β * psf. With the default β = false this overwrites psf; pass β = true to accumulate.

Running simulations

AtmosphericTurbulenceSimulator.SimulationBuffers — Type
SimulationBuffers

Everything one simulation run needs, in one place: the phase sampler (PhaseBuffers or SavedPhaseReader) with its output block phases and, when imaging is enabled, the OpticalBuffers, the ImagingPlan, the PSF block psf and the output image block images.

Internal to the simulation loop – the pieces are separately usable on their own, this only saves threading them through simulation_run. optical_buffers, img_plan, psf and images are nothing for a phases-only run.

Constructors: SimulationBuffers(pb) (a PhaseBuffers or SavedPhaseReader) for a phases-only run, and SimulationBuffers(T, atm_spec, img_spec; batch, deviceadapter) for imaging with output element type T. In the latter the phase plate is padded beyond the aperture so that the wind shift over the exposure fits, its grid step is img_spec.grid_step, and the plan is adapted to deviceadapter. The worker count for optical_buffers and the Harding interpolator is get_num_threads() at construction time.

AtmosphericTurbulenceSimulator.simulate_images — Method
simulate_images([T, true_sky::TrueSky, ]atm_spec::AtmosphereSpec, img_spec::ImagingSpec; n, [batch, file, verbose, savephases, deviceadapter])

Simulate n images using the provided imaging and atmosphere specifications and write the results to an HDF5 file.

Each batch is split across get_num_threads() workers (one by default); change the count with set_num_threads. Phase screens are drawn on a plate padded so that the wind shift over the exposure fits.

Arguments

  • T: output image numeric type; if not provided, defaults to Int for finite-photon simulations (determined by img_spec.readout_spec.nphotons) and to the number type of img_spec (that of its aperture) for infinite-photon models.
  • true_sky: a TrueSky model (e.g. PointSource, DoubleSystem, TrueSkyImage).
  • atm_spec: an AtmosphereSpec used to produce phase screens.
  • img_spec: an ImagingSpec describing the aperture and its grid step, readout, filter, exposure and image size.

Keyword Arguments

  • n: number of images to simulate.
  • batch: batch size for buffered computations and HDF5 writes (default 128).
  • file: output options. Can be a string (filename) or an HDF5File object. If set to nothing (default), no file is written and the images and phases are returned as a NamedTuple of arrays.
  • verbose: show progress meter (true by default).
  • savephases: when true (default), the sampled phase screens are saved in the HDF5 in dataset with key "phases".
  • deviceadapter: adapter for device-backed arrays (default identity, i. e. no transform). To use GPU arrays, pass e.g. CUDA.CuArray here (requires CUDA.jl).
source
